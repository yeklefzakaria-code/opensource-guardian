# Security Policy

## Supported versions

Security fixes are applied to the latest version on the default branch. This project is an early-stage security-review tool; its findings are heuristic and must not be treated as a guarantee that code is safe.

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in a public issue.

Use GitHub's **Private vulnerability reporting** feature for this repository, if available. Include:
- A clear description and potential impact.
- Reproduction steps or a minimal proof of concept.
- Affected commit, version, and environment.
- Any suggested mitigation.

We will acknowledge reports as soon as practical and coordinate a fix and disclosure with the reporter.

## Scope and safe harbor

Only test systems and repositories you own or have explicit permission to assess. Do not include real credentials, personal data, or private source code in public reports.
